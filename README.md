# Лабораторна робота №3
* lab_3_DML.sql` - скрипт для маніпуляції даними (INSERT, UPDATE, DELETE)
* lab_3_DQL.sql` - базові запити на вибірку, фільтрацію та сортування

# Лабораторна робота №4
* lab_4_view.sql - скрипт створення представлення v_Detailed_Orders для інкапсуляції складного JOIN-запиту
* lab_4_procedure.sql - скрипт створення збереженої процедури sp_AddNewProduct для додавання нового товару
* lab_4_trigger.sql - скрипт створення тригера trg_Products_BeforeUpdate
* test1.sql - скрипт перевірки та вибірки даних із представлення
* test2.sql - скрипт тестування процедури
* test3.sql - скрипт демонстрації роботи тригера
* Script.sql - скрипт створення необхідного нового стовпця updated_at для аудиту оновлень

# Лабораторна робота №5
* 4_explain_analysis.md - аналітичний файл із результатами виконання EXPLAIN до та після оптимізації
* `lab_5_analysis_optimization.sql` - скрипт діагностики та перевірки запиту за допомогою EXPLAIN
* `lab_5_commit.sql` - скрипт демонстрації успішного збереження змін за допомогою транзакції (COMMIT)
* `lab_5_complex_transaction.sql` - скрипт реалізації комплексної багатокрокової бізнес-транзакції для оформлення замовлення
* `lab_5_index.sql` - скрипт створення індексу для оптимізації та прискорення пошуку товарів
* `lab_5_rollback.sql` - скрипт демонстрації відкату змін у транзакції за допомогою ROLLBACK
